#### 7. Duplicate same-card adjudication: rescue the 8-deck twin the dedupe swallows

- **Cost:** ~$0.007/call; $0.00-0.04/session at the proposal's event estimate.

- **Caveats:** (a) **Build the local tracker + advisory prompt first** â€” the persistence prefilter IS the audit's own suggested non-AI fix (AUDIT:171), and since default mode needs a human tap anyway (the human can see the fanned cards), Claude's marginal value in default mode is only suppressing false prompts. ### Caching, structured outputs, batches
- **Structured outputs are GA via raw REST** (`output_config.format` json_schema, no beta header, no SDK) â€” use them on every new call; schemas need `additionalProperties:false`, no numeric min/max (validate counts locally); first call per schema pays a one-time grammar-compile hit (cached 24h). **Keep the `_json_block` regex fallback** for the shipped `bootstrap()`/`triage()` until they're migrated deliberately.
- **Prompt caching is mostly irrelevant here**: image blocks are cacheable, but changing any image invalidates the messages-tier cache, and nearly every call in this plan uses a fresh frame. The per-model minimum cacheable prefix is unsettled (live doc says 1,024 tokens for Opus 4.8; the 2026-06-04 skill cache says 4,096 â€” verify empirically via `usage.cache_creation_input_tokens` if it ever matters; a 4,784-token frame clears either bar). The one plausible use: the wizard referencing a single calibration frame across retries (or the beta Files API, `files-api-2025-04-14`, to upload it once instead of resending ~3.3MB base64).
- **Batches** for everything post-hoc: 100K requests / 256 MB per batch, most complete <1h, hard 24h expiry (persist `batch_id`, tolerate partial results), cache hits best-effort (use 1h TTL if caching at all). Never for anything live.
- **Latency budget** (estimate, not published â€” measure in-app before tuning fail-disabled timeouts): ~1-3s Haiku, ~3-8s Opus 4.8 with thinking omitted and `output_config.effort` low; the headline ~19-21s Opus TTFT benchmark is a max-effort-thinking config and not representative. Nothing here changes the verdict on per-frame use.

## 4. Deliberately rejected â€” do not re-propose

No proposals were killed in this verification round; the slate above is the survivors. The following are **standing rejections** (prior user decisions + research-confirmed dead ends):

1. **Per-frame / hot-loop vision** â€” rejected by explicit user decision (~$25-50/hr est., 1-4s+ latency vs 7-15s decision windows, approximate coordinates); research re-confirms: ~$86/hr at 1 fps full-res Opus 4.8, and nothing found supports hot-loop use.
2. **Any API call gating live advice** â€” fail-disabled is non-negotiable; API failure must degrade silently to current local behavior.
3. **Executor beyond one-key assist; real bet placement** â€” bets stay ghost-only; no full autonomy. (Computer-use tooling exists in the API; it is out of scope here.)
4. **anthropic SDK / playwright / pyautogui** â€” Claude via plain `requests` REST only; no new heavy deps.
5. **Claude (or any non-Gemini VLM) producing bounding-box geometry for training labels** â€” research verdict is firm: boxes come from the YOLO detector; Claude classifies/verifies crops only. (Gemini is the only frontier API with native box output, and it's outside the Claude-only constraint.)
6. **Normalized 0-1000 coordinates in prompts** â€” official docs explicitly say this works poorly; always request absolute pixel coordinates.
7. **Auto-accepting Claude geometry without human review** â€” docs call localization "approximate... verify outputs"; suggest-then-confirm is the only sanctioned pattern.
8. **Sending raw <200px crops** â€” docs warn of hallucination on small images; >=200px upscale is mandatory preprocessing.
9. **Roboflow hosted Auto Label / autodistill for the 52-class taxonomy** â€” Roboflow's own docs warn foundation-model labeling off fine-grained variants; no Claude module exists anyway.
10. **Live re-injection of "missed" cards from flap adjudication** â€” duplicate-card corruption risk via the `cx=None` add-branch; cut, not config-gated.
11. **Auto-apply card overrides without measured shadow-mode precision + explicit user sign-off** â€” exceeds the recorded V4 cold-path boundary (calibration + triage + post-hoc).
12. **Deleting the `_json_block` fallback wholesale** â€” shared by shipped `bootstrap()` and `triage()`; structured outputs apply to new calls only until a deliberate migration.
